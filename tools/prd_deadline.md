# PRD - 任务截止时间功能 (V13)

## 1. 概述

在任务管理中引入「截止时间」概念，帮助用户追踪任务的时间边界，提升时间管理能力。

## 2. 用户场景

用户在任务列表中长按某个任务，弹出截止时间配置面板，设置后任务卡片显示剩余时间/已超时提醒。

## 3. 功能详述

### 3.1 触发方式

- **长按任务卡片**（长按 500ms）→ 弹出截止时间配置面板
- 不影响原有的「点击开始任务」「左右滑动完成/删除」交互

### 3.2 截止时间配置面板

**UI 形态**：底部弹出的半屏面板（类似设置面板）

**配置项**：
| 字段 | 类型 | 说明 |
|------|------|------|
| 截止日期 | DatePicker | 年/月/日选择 |
| 截止时间 | TimePicker | 时：分 选择（可选，精确到5分钟） |

**快捷操作**：
- 「今天 18:00」
- 「明天 09:00」
- 「本周五 18:00」
- 「无截止时间」（清除）

### 3.3 任务卡片展示

**截止时间显示**（任务名称下方）：
| 状态 | 显示样式 |
|------|----------|
| 未超时 | 灰色小字：「截止 18:00」 |
| 剩余 ≤ 1小时 | 橙色小字：「还剩 45分钟」 |
| 已超时 | 红色小字 + 轻微闪烁：「已超时 2小时」 |

## 4. 数据结构

```javascript
// task 对象新增字段
{
  id: number,
  mode: string,
  text: string,
  completed: boolean,
  duration: number,
  prio: number,        // P1-P4
  energy: string,       // low/mid/high

  // 新增
  deadline: string | null   // ISO 8601 格式，如 "2026-05-03T18:00"
}
```

## 5. 交互流程

```
长按任务卡片 (500ms)
      ↓
弹出截止时间配置面板
      ↓
选择日期/时间 → 保存 / 清除截止时间
      ↓
任务卡片更新显示
```

## 6. UI 设计方向

- 配色：跟随任务所在模式的 Theme Color
- 截止时间面板：磨砂玻璃效果，与设置面板风格统一
- 快捷按钮：横向排列的 Pill 形按钮

## 7. 技术实现要点

1. **长按检测**：复用现有的长按逻辑（`LONG_PRESS_DURATION = 500`）
2. **日期时间选择**：使用原生 `<input type="datetime-local">` 或自定义组件
3. **超时检测**：每次 `renderTasks()` 时计算一次

## 8. 优先级

**高** — 核心功能补充，提升任务管理完整性

## 9. 预计工作量

中等（需新增面板、数据结构、计算逻辑）
